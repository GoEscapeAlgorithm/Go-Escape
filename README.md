# Go-Escape-AI

This project will use Renforcement learning to train an AI that can play Go Escape.

Team members:
  Allen, Steve, Ethan, & Nitin

environment.py is the human playable version, with spacebar as start level/jump and r as reset. gym_env.py trains a PPO agent to play one of the levels.
